# Phase 1, Step 1: Project and CI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An empty but real Daybook iOS app that builds, tests and lints with one command locally and in GitHub Actions.

**Architecture:** Two local SPM packages, one target each: `DaybookPlatform` (shared types and the location port) and `WeatherFeature` (the Weather tab, only `WeatherTab` is public). A thin app target generated by XcodeGen imports both. A Makefile gives identical commands locally and in CI.

**Tech Stack:** Swift 6 language mode, SwiftUI, Swift Testing, XcodeGen 2.45, GNU Make, bash, GitHub Actions on `macos-26`.

**Spec:** `docs/superpowers/specs/2026-09-19-phase1-weather-ios-design.md`. This plan covers build-order step 1 only. Steps 2 to 6 each get their own plan when reached. Phase 1b (Rust) is on hold.

## Global Constraints

- Every task is exactly one commit, made directly on branch `develop`. Never commit to `main`. Never push.
- Commit messages carry no `Co-Authored-By` trailer and no tool attribution.
- Minimum deployment target iOS 18.0. Xcode 26.6, Swift 6.3.3. Swift 6 language mode (`swift-tools-version: 6.0`, `SWIFT_VERSION: "6.0"`).
- Bundle identifier `com.blue-studio.daybook`.
- Simulator destination for every build and test: `platform=iOS Simulator,name=iPhone 17,OS=26.5`.
- No third-party dependencies in this step.
- No code comments unless the reason would genuinely surprise a reader.
- The generated `ios/Daybook.xcodeproj` and `ios/App/Info.plist` are never committed.
- Location usage string, verbatim: `Shows the weather where you are right now.`
- Tests use Swift Testing (`import Testing`, `@Test`, `#expect`), not XCTest.

public struct LocatedPlace: Sendable, Equatable {
    public let coordinate: Coordinate
    public let name: String?

    public init(coordinate: Coordinate, name: String?) {
        self.coordinate = coordinate
        self.name = name
    }
}

public enum LocationAuthorization: Sendable, Equatable {
    case notDetermined
    case denied
    case authorized
}

public enum LocationError: Error, Sendable, Equatable {
    case denied
    case unavailable
}

public protocol LocationProviding: Sendable {
    func authorization() async -> LocationAuthorization
    func current() async throws(LocationError) -> LocatedPlace
}

#!/usr/bin/env bash

app="${1:-ios/build/DerivedData/Build/Products/Debug-iphonesimulator/Daybook.app}"

[ -f "$app/PrivacyInfo.xcprivacy" ] || fail "privacy manifest missing from bundle"
plutil -lint "$app/PrivacyInfo.xcprivacy" >/dev/null || fail "privacy manifest is not a valid plist"

**Files:**

**Interfaces:**

`scripts/test-lint-layers.sh`:

#!/usr/bin/env bash
set -euo pipefail

here="$(cd "$(dirname "$0")" && pwd)"
tmp="$(mktemp -d)"
trap 'rm -rf "$tmp"' EXIT

make_feature() {
  local root="$1"
  mkdir -p "$root/Demo/Sources/Demo/UI" "$root/Demo/Sources/Demo/Providers" "$root/Demo/Sources/Demo/Store"
  printf 'struct OpenMeteoProvider {}\nprivate struct ForecastDTO {}\n' > "$root/Demo/Sources/Demo/Providers/OpenMeteoProvider.swift"

- [ ] **Step 2: Implement the lint**

`scripts/lint-layers.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

root="${1:-ios/Packages}"
status=0

for target in "$root"/*/Sources/*; do
  ui="$target/UI"
  providers="$target/Providers"
  [ -d "$ui" ] && [ -d "$providers" ] || continue

  names="$(grep -rhoE '(struct|class|enum|actor|protocol)[[:space:]]+[A-Za-z_][A-Za-z0-9_]*' "$providers" --include='*.swift' | awk '{print $2}' | sort -u)"

  for name in $names; do
    if hits="$(grep -rnwF "$name" "$ui" --include='*.swift')"; then
      echo "$hits" >&2
      echo "error: UI/ must not name '$name', which is declared in Providers/ ($target)" >&2
      status=1
    fi
  done
done

exit $status
```

Run: `chmod +x scripts/lint-layers.sh`
